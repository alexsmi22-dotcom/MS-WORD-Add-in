JCAMP-DX test fixtures for src/lib/__tests__/jcampCorpus.test.ts

Source: the JCAMP-DX official test set (jcamp-dx.org) and the R. J. Lancashire
compression test set, as redistributed in github.com/nzhagen/jcamp (MIT licence).
Each file keeps its own ##ORIGIN / ##OWNER header unchanged.

  compound.jdx, brukdif.jdx, fixdec1.jdx, pktab1.jdx            R. J. Lancashire (UWI, Mona) test set
  BRUKPAC.DX, BRUKSQZ.DX, BRUKNTUP.DX                           Bruker JCAMP-DX examples
  TESTSPEC.DX, TESTNTUP.DX, TESTFID.DX, ISAS_MS1.DX, IMSDEMO.DX ISAS Dortmund JCAMP-DX test files
  PE1800.DX, LABCALC.DX, scientific_notation_example.jdx,
  2Methyl1Propanol.jdx, 1HQuinine.jdx, ethanol_nmr.jdx          nzhagen/jcamp test data

NOT included: NIST WebBook / NIST SRD files (15 U.S.C. 290). The NIST rows of the
acceptance audit are pinned with small synthetic JCAMP files carrying the same
peak values, written inline in spectrumOverlay.test.ts.

oracle.json: a digest (point count, x/y range, y sum, 64 x-sorted samples) of what
the independent Python decoder `jcamp` 1.3.2 (nzhagen) reads from each file,
generated 2026-10-14 with `python -I` from a scratch venv. The JS reader is
compared against it point for point at the sampled indices.
