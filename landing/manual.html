Getting started

  1. Install. Unzip the pack for your machine and run the installer inside — install.bat on Windows, install.command on a Mac. No admin rights needed; it only registers the add-in for your own account.
  2. Restart Word completely. Close every window, not just the document. Word only notices a new add-in on a cold start — this is the single most common reason it "didn’t install".
  3. Open the pane. Insert → Add-ins → Developer Add-ins → JurisLab. It opens on the Home screen showing all 25 tools as cards, grouped by area.

Only the first load needs internet — the add-in fetches itself from the web once, then everything you type is computed on your own machine.

The core loop

Every tool works the same way, so once you’ve learned one you’ve learned all of them:

  1. Put your cursor where you want the content to land in your document.
  2. Pick a tool — click a card on the Home screen, or use the dropdown at the top. The Home filter chips (All / Science / Legal) narrow the cards to your kind of work; nothing is removed, just hidden.
  3. Type. A live preview appears as you go, showing exactly what will be inserted.
  4. Insert. The button drops it at your cursor. If it isn’t what you wanted, a single Ctrl-Z (⌘-Z on a Mac) removes it cleanly.
Try it: open Chemical, type H2O → the preview shows H₂O → Insert formatted text. Then type aspirin → a 2D structure appears with its formula and molecular weight.

Chemistry & structures

Five tools — Chemical, Build, Reaction, Mass Spec, Spectra.

🧪Chemical — formulas, 2D structures, properties & pKa

Two things in one panel. Type a formula and it typesets itself: H2O → H₂O, Ca(OH)2 → Ca(OH)₂, 2H2O keeps the coefficient full-size, SO4^2- → SO₄²⁻, Na+ → Na⁺, [Fe(CN)6]3- → the bracketed ion. Type a name, formula or SMILES and it resolves a 2D structure with a full readout.

  • Validation against a complete 118-element table: real-element check, balanced brackets, nested groups (K4[Fe(CN)6]), hydrate dots (CuSO4·5H2O), net charge, molecular weight, and the normalized Hill formula. The readout is either ✓ Valid — CaH2O2, M = 74.093 g/mol or ⚠ with the exact error.
  • Structure drawn by OpenChemLib; isomeric SMILES (C[C@@H](N)C(=O)O) is drawn with wedge/hash bonds. Known compounds are recognised back from the drawing (a dictionary lookup, not a general IUPAC namer).
  • Physicochemical properties: MW, heavy-atom count, cLogP, logS, tPSA, H-bond donors/acceptors, rotatable bonds.
  • Druglikeness: Lipinski Rule of Five (≤1 violation passes) and Veber (rotatable ≤10, tPSA ≤140), compared on unrounded values.
  • pKa by exact ionizable-group detection on the atom graph (carboxylic acid ≈4.5, phenol ≈10, aliphatic amine ≈10.6, aniline ≈4.6, and ~a dozen more, including polyprotic acids), plus the estimated net charge at pH 7.4.
Try it: aspirin → structure, formula C₉H₈O₄, MW, druglikeness, and “Carboxylic acid — acidic, pKa ≈ 4.5”. Ca(OH)2 → ✓ Valid — CaH2O2, M = 74.093 g/mol.

Inserts: formatted formula (text), structure (picture with provenance), recognised name (text), or the properties + pKa block (text with its caveats).

Honest about estimates. cLogP/logS are model predictions (RMSE ≈ 0.4 / 0.7 log units; shown as n/a for inorganics). pKa is a group estimate, not a compound-specific value — the group detection is exact, the number is a typical literature figure. Online IUPAC lookup (OPSIN) is the one feature that leaves the machine, and it always asks first.

🔬Build — structures from atoms/bonds, Markush & molfiles

Draw a structure by describing it, or paste an MDL molfile. Built for patent genus/Markush work.

  • Atom/bond DSL: atoms: C C O (1-indexed) and bonds: 1-2 2=3 where -/=/# are single/double/triple, ~ is any, i>j/i<j are wedge/hash. Atoms carry charge (N+, Fe2+); hydrogens auto-fill.
  • Markush / generic atoms: [C,N] variable-atom list, X halogen, A any atom, Q any heteroatom, R1/R2… R-groups.
  • Query features in trailing braces: {ar} aromatic, {r6} ring size 6, {har} heteroaromatic, {ring}/{chain}, substitution constraints — on atoms and bonds.
  • Molfile: paste any MDL V2000/V3000 (auto-detected).
  • R-group legend generated as an inline line or a two-column table, with shorthand expansion (C1-6 alkyl → C₁–C₆ alkyl, opt sub phenyl → optionally substituted phenyl).
Try it: atoms: C O O / bonds: 1=2 1=3 → CO₂. A ring with [C,N] spans benzene and pyridine and is reported as a generic structure.

Inserts: the structure (picture with provenance), optionally followed by the R-group legend (paragraph or table). Query structures report MW as “generic structure”, by design.

⚗️Reaction — reaction-scheme layout

Compose a scheme from names/SMILES: reactants + reactants >> products ; over ; under. Arrows: >>/-> forward, <=>/⇌ reversible, <- retrosynthetic; multi-stage chains are supported. The two optional ; fields are text over/under the first arrow.

Try it: CCO + CC(=O)O >> CC(=O)OCC ; H2SO4 ; reflux → ethanol + acetic acid → ethyl acetate, “H2SO4” above and “reflux” below a forward arrow.

Inserts: the whole scheme as one picture with provenance.

Layout only. Reaction draws what you type — it does not balance equations, predict products, or check feasibility. Arrow type and conditions are yours to state.

⚛️Mass Spec — exact mass, isotope pattern, adducts

From a name, formula or SMILES:

  • Monoisotopic and average mass.
  • Isotope pattern by exact discrete convolution over NIST abundances — peaks M, M+1, M+2… as offset, exact centroid mass, and intensity normalised to base = 100.
  • Adduct m/z for nine ESI adducts: [M+H]⁺, [M+Na]⁺, [M+K]⁺, [M+NH₄]⁺, [M+2H]²⁺, [M−H]⁻, [M+Cl]⁻, [M+HCOO]⁻, [M−2H]²⁻ — with electron-mass correction. Omitted automatically for an already-charged input.
Try it: glucose → monoisotopic 180.0423, average 180.159; [M+H]⁺ 181.0495, [M+Na]⁺ 203.0315, [M−H]⁻ 179.0350. A chlorinated compound shows the tell-tale ~32% M+2 peak.

Inserts: a text summary (masses, pattern with %, adducts). Untabled elements are excluded from the pattern shape only, with a note; masses stay exact.

📡Spectra — predicted NMR, 2D, IR, UV-Vis & MS fragmentation

Pick a spectrum type, type a name or SMILES, and get a prediction with an assignment for every signal. Seven kinds:

KindWhat you get
¹H NMRSymmetry-distinct signals: shift, integration, multiplicity — with coupling refinement adding J values and multiplet names (dd, td…).
¹³C NMRGrant–Paul additivity (sp³) + aromatic increments; carbonyl classes separated (ketone ≈205, ester ≈171…).
COSY (2D)¹H–¹H cross-peaks from the exact coupling topology, with typical J by relationship (ortho ≈7.8, meta ≈1.5 Hz…).
HSQC (2D)One-bond ¹H–¹³C correlations — one peak per protonated carbon (topology exact).
IRCharacteristic group frequencies with range, intensity, broad flag; carbonyl class separation; conjugation lowers C=O.
UV-Visπ→π* λmax by Woodward–Fieser, every increment listed for audit; “transparent” out of domain rather than a guess.
EI-MS fragmentationMolecular ion + fragments with exact m/z, pathway (α-cleavage, tropylium, McLafferty…), and a likelihood ranking.
Try it: toluene, ¹H → δ 2.4 (3H, s, CH₃ on Ph) plus the aromatic signals. toluene, EI-MS → tropylium m/z 91.0542 ranked high (its real base peak). acetophenone, IR → C=O ≈1690, labelled conjugated.

Inserts: a data table (with caveats), and where chartable a spectrum image — NMR stick, IR trace, MS stick, or a 2D COSY/HSQC map.

Read before using Spectra. These are estimates from published additivity rules — structure recognition is exact, the numbers carry real uncertainty (¹H ±0.2–0.4 ppm, ¹³C ±2–4 ppm, IR ±10–30 cm⁻¹, UV-Vis ±5 nm in domain). OH/NH shifts are nominal ranges; aliphatic J is the ~7 Hz freely-rotating average; alkene J is nominal without defined cis/trans; the IR fingerprint region below ~1500 cm⁻¹ is not predicted; MS “likelihood” is a ranking, not an intensity. Use it to assign peaks you already have. The caveat block is never omitted.

Math & units

Six tools — Math, Solve, Units, Plot, Stats, Analyze.

∑Math — native Word equations

Type x^2 + y^2 and insert a real Word equation (click it and Equation Tools appear — editable, not a picture). If the host is too old or the expression won’t parse, it falls back to formatted text and tells you.

  • Fractions a/b, scripts x^{n+1}, roots sqrt(x)/root(n,x), abs/floor/ceil/norm.
  • N-ary sum(i=1,n,e) Σ, prod ∏, int(a,b,e) ∫ (plus oint/iint), lim(x->0, e).
  • Matrices matrix(a,b; c,d) (and pmatrix/bmatrix/vmatrix), cases(…) piecewise, multi-line align(a=b; c=d), accents bar/hat/vec, Dirac bra/ket/braket.
  • Greek by name, logic/set-theory symbols, and operators (<= → ≤, -> → →, +- → ±). Implicit multiplication (2x, 2(x+1)).
  • Formula library dropdown with 21 categories (statistics, calculus, physics, engineering, four finance groups…). LaTeX import (paste, convert) and copy-as-LaTeX out. Tick Number this equation for an auto-incrementing (I), (II)….
Coming from LaTeX? Paste \frac{-b \pm \sqrt{b^2-4ac}}{2a} and convert it to a Word equation — the quadratic formula as a true stacked fraction with a radical.

Inserts: a native Word equation object, or inline formatted-text runs matching the preview.

🟰Solve — equations, calculus & word problems

A no-code solver that runs entirely on your machine. Pick what to do from the dropdown:

  • Solve an equation — x^2 - 5x + 6 = 0 → x = 3, 2 exactly; linear and quadratic are closed-form (complex roots included). Higher-degree and transcendental equations (cos(x) = 0) give real roots numerically over a scanned range. Identities and no-solution cases are reported as such; a multi-unknown equation is refused, not guessed.
  • Differentiate — a symbolic derivative: sin(x^2) → cos(x^2)*2*x (chain rule; the value is exact).
  • Definite integral — numeric (adaptive Simpson): x^2 from 0 to 3 → 9. Limits may be expressions like pi/2.
  • Word problem — offline templates for percentages (12 is what percent of 48? → 25%), distance = rate × time, and simple “a number …” sentences (twice a number plus 7 is 15 → builds 2*n + 7 = 15, n = 4).

Inserts: the solution as text — the variable, each root/answer, the method label, and steps.

Exact answers are labelled exact; numeric answers state their limits (real roots only, within the scanned range; integration is an approximation). Word problems say so when they can’t template a problem rather than inventing an answer — the honest half of a “both, offline first” design. An optional online AI solver for free-form problems can be added.

📏Units — SI typesetting & conversion

  • Typesetting: 9.81 m/s^2 → 9.81 m/s², uncertainties 5.0 +- 0.2 kg → 5.0 ± 0.2 kg, scientific notation 1.2e-3 mol/L → 1.2 × 10⁻³ mol/L, symbol fixes (ohm → Ω, degC → °C, um → µm, angstrom → Å).
  • Conversion across length, mass (incl. Da/kDa), time, temperature (°C/°F offsets handled), volume, pressure, energy, amount, angle, and electrical units — including compound units (km/h → m/s, g/mol → kg/mol). Results are given to 4 significant figures.
Try it: 1 km → mi → 0.6214 mi; 100 °C → °F → 212 °F.

Inserts: the typeset quantity or the conversion line. Incompatible or unknown units are refused, not fudged.

📈Plot — function & data charts

  • Functions: one or more expressions separated by ; (each its own labelled line), over an x-range. Full function set (trig, hyperbolic, exp/log/sqrt, min/max/hypot…), constants pi/e/tau. No eval — safe expression parsing.
  • Data: one point per line, x y or x y err (the third column draws an error bar). Functions and data can overlay, with a legend.
Try it: x^2; exp(-x^2) → two labelled curves with a legend; data lines 1 2 / 2 4.1 0.3 → scatter points with an error bar.

Inserts: the chart as a PNG picture, drawn entirely offline.

📐Stats — tests, regression & uncertainty

Pick a test, paste your numbers (space/comma/newline separated), get a paper-ready result with a real p-value computed from distribution functions (not table lookups). Eleven tests plus two utilities:

  • Descriptive statistics (n, mean, SEM, SD, median, 95% CI, CV); two-sample t-test (Welch or Student); paired t-test; one-way ANOVA; linear regression (slope/intercept/R²/slope p).
  • Non-parametric: Mann–Whitney U and Wilcoxon signed-rank (normal approximation, tie- and continuity-corrected).
  • Chi-square goodness-of-fit and test of independence (r×c); two-way ANOVA (balanced, with replication).
  • Utilities: uncertainty propagation (value ± combined 1σ, with the largest-contributing variable), and multiple-comparison correction (Benjamini–Hochberg / Holm / Bonferroni).
Try it: one-way ANOVA on 1 2 3 / 4 5 6 / 7 8 9 → F(2, 6) = 27.00, p ≈ .001. Regression on x = 1..5, y = 2.1 3.9 6.1 8.0 9.9 → slope ≈ 1.97, R² ≈ 0.999.

Inserts: the result block as text (APA-style, e.g. t(18) = 2.41, p = .027). Zero-variance or too-few-points inputs get a clear guard message.

🧮Analyze — a no-code numerical workbench

Fourteen sub-tools, each pre-filled with a worked example; results (matrices, text, and inline plots) insert at the cursor.

  • Linear algebra: solve A·x = b, inverse, determinant/rank/trace, eigenvalues (symmetric — with vectors; and any square matrix — complex pairs as a ± bi), QR, SVD, matrix multiply, transpose, and a MATLAB-style matrix expression evaluator (A*inv(B) + 2*A').
  • Optimization: minimise a typed function (Nelder–Mead); reports the minimum, its location, and whether it converged.
  • FFT: radix-2 amplitude spectrum + top-3 dominant frequencies + a chart.
  • Data → insights: paste a table → per-column summaries, Pearson r (with p) and Spearman ρ for every numeric pair, trends vs row order, outlier/missing flags, and a plain-language write-up. Every figure traces to an input cell.
  • Solve an ODE / system: type the equation you have — higher order is auto-reduced to a first-order system (up to order 6). Solver Auto starts explicit (RK45) and switches to an implicit stiff method (RODAS4) mid-run when the problem turns stiff. Optional report-at times (computed exactly, not interpolated) and a “stop when this hits zero” terminal event.
Try it: eigenvalues (general) of 0 -1 / 1 0 → ±i. Optimise the Rosenbrock function from x=-1.2, y=1 → min ≈ 0 at (1, 1). ODE y'' = -y, y=1, y'=0, 0..2π → y = cos t, ending y ≈ 1 (“auto-reduced to 2 states”).

Inserts: text lines, matrices as editable Word tables, and inline plots (FFT spectrum, ODE trajectory). Singular matrices are reported as exactly that, never faked.

Data & figures

Two tools — Table → Chart, Finance.

📊Table → Chart — turn a Word table into a graphic

Click inside a Word table, press Read selected table, and it auto-picks the best representation (you can override with Show as).

  • 10 chart types: column, bar, line, area, scatter, stacked column/bar/area, pie, doughnut. Tolerant number parsing handles 1,234.5, $2,500, 45%, accountant negatives (1,200) → −1200, and magnitude suffixes 1.2K → 1200.
  • Diagrams from text tables: flowchart (each row a step; a leading S101 becomes a reference numeral; a row ending ? is a decision diamond) and block diagram (System | Subsystem | Component paths merged into connected boxes).
  • Table figure: draw the table itself as a clean exhibit, preserving section bands.
  • Patent style (B&W): 37 CFR 1.84 line art — series distinguished by hatch fills, dash patterns and markers instead of colour, with an optional “FIG. N” label and reference numerals with lead lines.
  • PowerPoint export: a native editable chart, a native editable table, or native diagram shapes (auto-paginated), optionally with the source table on a second slide.
Try it: a table Year | Revenue with 2021 $1,200 / 2022 $1,500 / 2023 (200) → the accountant parentheses become −200; “Show as = Column” renders a column chart with a zero line; Patent style hatches the bars and captions “FIG. 1”.

Inserts: a figure at the cursor (picture), an editable Word table, or a downloaded .pptx. Tables over 24 rows get a “this will be dense — try the table figure” warning.

💵Finance — 20 calculators

Pick a calculator; rates are entered as percentages; the result computes live. Twenty calculators, each backed by a pure function:

  • Time value of money: future value, present value, compound interest, growing-annuity PV, effective annual rate.
  • Loans: payment, amortization summary (payment / total interest / total paid), declining-balance depreciation schedule.
  • Project & valuation: NPV, IRR, XIRR (dated flows), DCF with a Gordon terminal value, annualized return / volatility / Sharpe.
  • Options (Black–Scholes, European, no dividends): price, Greeks (delta/gamma/vega/theta/rho), implied volatility.
  • Bonds: price, yield to maturity, duration & convexity.
Try it: future value pv 1000, 5%, 10 yr → 1,628.89. Bond price face 1000, 5% coupon, 6% YTM, 10 yr → ≈ 925.61 (a discount, since YTM > coupon).

Inserts: the result as text or a small labelled table. Where a model has hidden assumptions (IRR reinvestment, Black–Scholes no-dividends, DCF terminal-value sensitivity, clean bond price…), an “assumes” note is shown and carried into the inserted text.

Biology

Seven tools — Sequence Map, Align, Sequence (ST.26), DNA, Bio/Assay, Peptide, Botanical.

🗺️Sequence Map — open a file, draw an annotated map

Open a sequence file (or paste one) and insert an annotated map at the cursor. Files are read locally as bytes; nothing is uploaded. Format is sniffed by content, not extension.

FormatWhat you get
GenBank .gb .gbk .gbffThe one that draws a real map — it carries the feature annotations (promoters, CDS, resistance markers, origins) and topology. Full location grammar: ranges, partial bounds, complement(...), join(...).
FASTA .fa .fastaSequence only — backbone and scale, no features. FASTA carries no annotations or topology, and the tool never guesses them.
SnapGene .dnaRead where possible; falls back to “export as GenBank” with a message rather than a wrong sequence.

Plasmids draw as circular maps, linear constructs as linear, and Auto follows the record’s own topology. Joined CDS draw as segmented arrows with a dashed intron connector; restriction sites can be overlaid; a black-and-white patent-figure style is available.

Methylation changes what actually cuts. The site list is what the enzyme recognises; whether it cuts depends on how the DNA was grown. MboI won’t touch plasmid DNA from a dam+ strain; DpnI cuts only methylated DNA. Both are flagged under the digest table.

🧬Align — pairwise sequence alignment

Compare two sequences and insert the alignment at the cursor. Needleman–Wunsch (global) and Smith–Waterman (local) with affine gaps — the algorithms EMBOSS needle and water run, at their default costs (BLOSUM62, gap open 10 / extend 0.5 for protein; +5/−4 for DNA). Paste plain sequence or FASTA; headers and whitespace are stripped. Sequence type auto-detects conservatively (DNA only when ≥90% ACGTUN).

Global forces an end-to-end alignment — use it when the two sequences are the same thing (a clone vs its reference). Local finds the best shared segment — use it when they share only a domain. The stats line reports identities, similarities, gaps, and 1-based spans; the ruler uses | (identical) and : (similar).

Percent identity is a fact about the alignment, not the sequences — it moves when you change the gap costs. Below ~25% identity (the “twilight zone”) two unrelated proteins still align convincingly, and JurisLab says so. The alignment inserts in a monospace font deliberately: a proportional font would silently break the column correspondence the ruler depends on.

🧬Sequence — WIPO ST.26 listings

Generates a well-formed WIPO Standard ST.26 XML sequence listing — the mandatory format for patent sequence filings.

  • Metadata: applicant, invention title, file reference, IP office, application number, filing date (production date auto-set).
  • Per sequence: molecule type (DNA/RNA/Protein), a mol_type from the ST.26 controlled vocabulary, organism (blank → “synthetic construct”), and residues (validated per alphabet; invalid characters flagged).
  • Feature annotations: CDS, gene, mRNA, misc_feature, sig_peptide, mat_peptide, with location and /gene, /product, /note qualifiers.
  • Auto /translation for a simple-location CDS on a nucleotide sequence (with /codon_start 1), plus advisory warnings (CDS length not a multiple of 3, sub-length sequences).
Try it: a DNA card with residues ATGCAAAGCTAA and a CDS at 1..12 → the builder emits /translation MQS inside a complete ST26SequenceListing document.

Output: the XML is shown with Download and Copy buttons (not inserted into the document).

Always validate ST.26 output in the WIPO Sequence tool before filing. JurisLab generates the listing; it is not a substitute for WIPO’s own validator.

🧬DNA — nucleotide analysis

Live analysis of a DNA/RNA sequence (IUPAC codes accepted):

  • Reverse complement (RNA-aware), complement, and transcription (T→U).
  • Translation in any of six frames; degenerate codons resolve when unambiguous (GCN → Ala), else X; optional stop-at-first-stop.
  • Base composition & GC%; a six-frame ORF finder with a minimum-length filter, coordinates 1-based on the (+) strand for both strands, inserted as a table.
  • Primer Tm by nearest-neighbour SantaLucia (1998) thermodynamics with salt and primer-concentration corrections (defaults 50 mM Na⁺, 0.25 µM); below 8 nt it falls back to the Wallace rule and says so.
  • Protein properties of the translation: MW (ProtParam masses), pI (EMBOSS pKa values), GRAVY (Kyte–Doolittle).
  • Restriction sites from a ~110-enzyme table (both strands, IUPAC-degenerate, Type IIS), with cut positions and overhangs, unique cutters starred, and methylation warnings (Dam/Dcm/DpnI).
Try it: ATGGCCAAGCTTGATTAA → mRNA AUGGCCAAGCUUGAUUAA; +1 translation MAKLD*; reverse complement TTAATCAAGCTTGGCCAT; a HindIII site at A^AGCTT.
Primer Tm is meaningless without its conditions. The readout always echoes them, and warns that it assumes a perfectly matched duplex — no mismatches, hairpins or primer-dimers, and it says nothing about specificity.

🧫Bio/Assay — kinetics, dose–response, binding & lab math

Pick one of 13 calculators. Four fit a curve with a shared Levenberg–Marquardt engine that reports parameters ± standard errors and R² and draws the fit over your data; the rest are closed-form lab maths. You never enter starting values — each fit seeds itself from a linearization.

  • Fits: Michaelis–Menten (Vmax, Km); Hill (Vmax, K, coefficient n); dose–response 4PL (IC50/EC50, orientation inferred from the data); one-site saturation binding (Bmax, Kd).
  • Lab maths: Ki from IC50 (Cheng–Prusoff, with competitive / uncompetitive / non-competitive / mixed modes — mixed is refused, since one IC50 can’t separate Ki and Ki′); catalytic efficiency (kcat, kcat/Km); Henderson–Hasselbalch; Beer–Lambert; dilution (C₁V₁ = C₂V₂); serial-dilution plan; nucleic-acid concentration (A260); protein concentration (A280).
Try it: Michaelis–Menten on the default data → Vmax = 12, Km = 8, R² = 1, with the hyperbola drawn over the points. Ki from IC50 (IC50 100, [S] 8, Km 8, competitive) → Ki = 50.

Inserts: the result text and, for fits, the data+fit plot as a picture.

R² is a poor guide for a nonlinear fit — it stays near 1 even when a parameter is undetermined, so the tool warns you to judge by the standard errors and residuals. It flags any parameter whose SE exceeds 25% of its estimate, warns when your substrate range can’t separate Vmax from Km, and notes that least squares can’t tell you the model is wrong.

🔗Peptide — draw a peptide from its sequence

Type an amino-acid sequence in one- or three-letter codes (ACDEFG, Ala-Gly-Cys) and get its 2D structure, residue count, molecular formula, and molecular weight. All 20 standard amino acids are supported (proline’s ring and glycine handled correctly); unrecognised tokens are reported, not dropped.

Try it: AG (or Ala-Gly) → 2 residues, formula C₅H₁₀N₂O₃, MW ≈ 146.14. Single residues equal their free amino acid.

Inserts: the 2D structure as a picture, with formula/MW/SMILES in the alt-text.

Connectivity only — no stereochemistry. Cα chirality is left undefined so the tool never asserts a possibly-wrong configuration. Standard-20 residues only (no modifications or disulfides); long chains render dense.

🌿Botanical — plant nomenclature & trait tables

Typesets a scientific name with correct ICN/ICNCP italics, and builds a varietal “characteristics” table.

  • Genus and species/infraspecific epithets italic; rank connectors (subsp., var., f.…) roman, and they re-italicize the epithet even after an author citation; author citations roman; hybrid × roman; cultivar epithets roman in straight single quotes.
  • Trait table: one Label: value per line → a bordered two-column table with bold labels.
Try it: Rosa × hybrida 'Peace' → Rosa × hybrida 'Peace'. Quercus robur L. subsp. robur → Quercus robur L. subsp. robur (the rank connector re-italicizes after the author).

Inserts: the typeset name (true italics) and the trait table as native Word rich text.

Patent drafting

Four tools — Numerals, Refs, Code, Audit.

🔢Numerals — reference-numeral management

Maintains a numeral → element table saved in the document, inserts callouts, and reconciles the table against the text.

  • Per row: an integer numeral and an element name; a next-numeral suggestion (10 to start, then the even-number convention 12/14…). Parenthesize toggles (12) vs 12.
  • Scan document reports four findings: collisions (one numeral, two elements), gaps, orphans (a callout with no entry), and unused entries. Prose numbers like “12 mm” or “2024” are deliberately not matched.
  • Inserts the sorted List of Reference Numerals as a two-column table under a heading.
Try it: table 10 base / 12 housing / 14 cover, document calls out (10)(12)(14) → “✓ no issues”. Add a 12 cover row → a collision on 12.

🔖Refs — captions & cross-references

Auto-numbered figure/table captions with per-document running counters (inserted with Word’s built-in Caption style), in-text cross-references (Fig. 3, Table 2, Eq. (1)), and a Check captions pass that flags gaps and duplicates per kind.

Try it: insert a figure caption → “Figure 1. …”, the counter advances to 2. A document with Figure 1 and Figure 3 → check reports “missing 2”.

For live auto-renumbering across a long document, Word’s own cross-reference fields remain the authority; this is the lightweight authoring aid.

💻Code — algorithm & code listings

Renders pseudocode or source as a monospace, whitespace-preserving block with an optional caption and line numbers. Algorithm style additionally bolds control-flow keywords (function, if, then, for, while, return…), preserving your case; Code listing style is verbatim. Everything is HTML-escaped, so a < b && c renders literally.

Try it: paste pseudocode with function/if/return, Algorithm style, caption “Algorithm 1: KeyGen” → keywords bold, numbered lines, caption above.

✅Audit — whole-document consistency

One Check this application pass runs every cross-reference rule at once and returns a per-section report:

  • Reference numerals — the same collisions / gaps / orphans / unused reconciliation as Numerals.
  • Sequences — SEQ ID NO references reconciled against the ST.26 listing count (out-of-range citations, uncited sequences).
  • Figures — continuity of referenced figure numbers (handles FIGS. 1-3, Figures 2 or 4).
  • Cross-references — every Fig. N/Table N in prose should have a matching caption.

Output: a read-only report in the pane; a clean document reports “✓ No issues found.” Nothing is inserted.

⚖️Citations — Bluebook citations, TOA & TOC

A config-driven Bluebook citation formatter with 11 types, correct italics, and practitioner or academic typography.

  • Types: case (full & short form), Id., supra, statute (U.S.C.), regulation (C.F.R.), patent, patent-application publication, Federal Register, MPEP section, law-review article, book/treatise.
  • T6/T10 abbreviation (Corporation → Corp., International → Int’l, California → Cal.), with the named-party exception so a state that is the party stays spelled out. Reporter, court, date, and patent-number normalization, with a ⚠ on an unrecognised reporter and rejection of impossible dates (Feb 31).
  • Paste & fix parses a pasted citation into the right type and fields for review.
  • Table of Authorities in FRAP 28(a)(3) order — a static formatted list, or native Word TA/TOA fields that produce live page numbers on F9. Table of Contents from your Heading 1–3 styles as a native TOC field.
Try it: case Alice Corp. v. CLS Bank Int'l, 573 U.S. 208, pincite 216, 2014 → Alice Corp. v. CLS Bank Int’l, 573 U.S. 208, 216 (2014). Abbreviate “National Association of Manufacturers” → Nat’l Ass’n of Mfrs.

Inserts: the formatted citation at the cursor; the TOA as a static list or native fields; the TOC as a native field (press F9 to populate).

A drafting aid, not the full manual. It applies common Bluebook conventions — verify against the current edition. Static TOA text can’t recover page numbers; only the native-field path plus F9 can.

Honest limits — what JurisLab does not do

Knowing where a tool stops is what makes the rest of it trustworthy.

  • It is a drafting aid. Verify every structure, formula, calculation and listing before filing or publishing. It is not a reviewer.
  • Predicted spectra are estimates, not measurements — see the Spectra warning above.
  • pKa is a functional-group estimate, not a compound-specific prediction. The group detection is exact; the value is a typical literature figure.
  • The Solve/ODE tools are numerical where they say so — real roots within a scanned range, numeric integration, no closed-form ODE solutions, no boundary-value problems or PDEs.
  • IR predicts group frequencies, not the fingerprint region below ~1500 cm⁻¹.
  • UV-Vis uses the Woodward–Fieser rules, which have a defined domain; outside it, JurisLab says “transparent” instead of guessing.
  • Reaction is a layout tool — it doesn’t balance, predict, or check feasibility.
  • ST.26 listings need WIPO validation, and citations need a Bluebook check, before filing.
  • Word on the web / older Word: native equations need a recent Word. Where they aren’t available, JurisLab inserts formatted text instead and tells you it did.

Troubleshooting

SymptomWhat to do
The add-in doesn’t appear after installingFully close and reopen Word — all windows, not just the document. This is the usual cause. Then look under Insert → Add-ins → Developer Add-ins.
The pane is blank or won’t loadYou need internet for the first load. If it’s still blank, close the pane and reopen it. If it persists, reinstall from the current pack — an older install can point at an address that no longer exists.
A banner says a new version is availableReload the pane (close and reopen it). You don’t need to reinstall — the add-in updates itself from the web.
“Couldn’t build an equation from that”The expression didn’t parse, so it inserted formatted text instead. Check for an unclosed bracket. The Examples & syntax panel shows the syntax for what you’re typing.
The preview shows an errorTrust it — that’s the preview doing its job. Nothing is inserted until you click Insert.
An ODE says it stalled or looks stiffSet the solver to Auto (or Implicit). If it still won’t finish, the solution may genuinely blow up in finite time — try a shorter range.
A structure name isn’t recognisedTry its SMILES, or enable the opt-in online IUPAC name lookup when prompted.
Something inserted that you didn’t wantCtrl-Z (⌘-Z on a Mac). Every insert is a single undo step.
