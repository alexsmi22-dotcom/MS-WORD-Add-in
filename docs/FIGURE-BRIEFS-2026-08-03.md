# Figure implementation briefs — remaining Engineering tools (2026-08-03)

Produced by five read-only mapping agents; every field name below was verified
against the engine source. Consumed batch by batch as the figure ratchet climbs
(53 of 130 when this file was written). Line numbers drift with every edit —
re-grep the tool id; everything else stays true. Delete when the ratchet hits 130.

Conventions for every conversion (verified across all 5 briefs):
- All listed tools end `return { text: plainDashes(lines.join("\n")) };` → convert to
  `return engReport(lines, [{ kind: "plot", svg, caption, alt, w, h }]);` with the
  text-only return kept as the degenerate-case fallback. engReport plainDashes-es
  lines AND caption/alt itself.
- Sweeps re-call the exported engine per point (never re-derive formulas); skip !ok points.
- Log axes silently drop non-positive points via dropForScales — never log an axis
  whose data legitimately reaches 0. Landmark/marker series: omit `label` or the
  legend gains a row per landmark.
- buildPlotSvg has NO bar type and draws NO zero line — stems/baselines are explicit
  2-point line series. No aspect control — anything whose ANGLE or AREA RATIO is the
  content needs a custom equal-aspect builder in mechchart.ts (copy trussSvg's scale
  math: s = min(pw/dx, ph/dy) with 1e-9 floor, centred ox/oy). Literal hex only
  (insertedFiguresIgnoreTheme.test.ts scans lib sources with <svg).
- NEW SHARED BUILDER STILL OWED (for chips-thermal, chips-timing, thermo-vapour):
  generalise npshLadderSvg into `ladderSvg(rows: {name, delta, gain}[], opts
  {title, axisLabel, fmt, limit?, limitLabel?, limitOkAbove?, resultName,
  okText?, failText?})` — npshLadderSvg's private n1=toFixed(1) prints "0.0" for
  picoseconds/milliwatts, so fmt is a param. RECORDED DEVIATION (v2.86.0): the
  three ENERGY ledger tools shipped WITHOUT it — energy-combustion as signed
  hBarSvg mass-balance rows (conservation-exact, judged equivalent), energy-hydro
  and energy-storage via their brief-sanctioned plot alternatives. The chips/
  thermo-vapour batch must still build ladderSvg. Second recorded deviation:
  energy-wind-shear ships only the (v, h1) measurement marker, not the briefed
  h2 markers — at h2 there are TWO candidate speeds (one per law) and a marker
  pair there implied a false precision; the curves end at 1.25·h2 regardless.
